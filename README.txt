NIGHTHAWK UI ELEMENTS ARCADE

This folder contains a complete static website for GitHub Pages.

1. Extract the ZIP on your computer.
2. Upload index.html into your GitHub Pages repository, or into a separate game folder in that repository.
3. Keep the filename index.html. Your published folder will open it automatically.
4. If GitHub Pages is already enabled, let the updated site finish publishing, then refresh the page.

Upload the extracted file, not the ZIP itself. You can also open index.html directly in a browser to play locally.

All styles, game code, and school logos are embedded in index.html. No installation or additional image files are needed.

GAME
Level 1: ID naming rules, 10 correct answers, 100 points.
Level 2: ID Repair Shop, 5 typed answers, 50 points.
Level 3: Build the App, 15 correct placements, 150 points.
Full challenge: 300 points.
Correct answers earn 10 points. Incorrect answers and unclicked balloons do not change the score.
Restart replays the current level. Level 2 includes Clear Answer.
Test Level 2 and Test Level 3 buttons let you preview those activities directly.

This game does not submit or save student scores to GitHub.
